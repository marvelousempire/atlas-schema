# Column: Studio-Console-Cassette

Studios, consoles, cassettes — a hierarchy parallel to the cosmology.

- **Studio** = the environment that contains consoles. The ACT V4 canvas is the studio-surface.
- **Console** = the operating surface. Where you interact. Reason's rack. The ACT V4 canvas modes.
- **Cassette** = sealed content. Atlas is a cassette that plays in any console.

The canvas is not a window onto the system. It IS the system, wearing a face. Go and Rust hybrid for instant loading. WebGPU for fluid motion. Event bus for sync. Nothing breaks your focus.
