# atlas-schema

The Atlas schema: the complete cosmology hierarchy and its parallel vocabulary columns. This is the ultimate reference for how every repository in the marvelousempire family is structured, numbered, and sealed.

## The Eight Levels (Cosmology Column)

Level zero is pure acknowledgment — Thought/Omni. Nothing ascertained yet. Things passing by.

1. **Thought/Omni** — the unthinkable realm that became concept. Level zero: acknowledgment only.
2. **Supercluster** — Laniakea scale. A hundred thousand galaxies.
3. **Galaxy** — a group of multi-site networks living together.
4. **Universe** — the master site. that-app-studio. The organization level.
5. **Planet** — each child site of the master. Atlas-that is a planet.
6. **Console** — the operating surface. The ACT V4 canvas is the studio-surface.
7. **Cassette** — sealed data, zero logic. Atlas is a cassette that plays in any console.
8. **Micro-slice** — the floor. The substrate beneath seedTHAT. The smallest purchasable unit on the shelf before assembly begins. SeedTHAT builds upward from micro-slices. SliceTHAT is the only reverse path.
